# veter-peremen
«Ветер Перемен» — литературная онлайн-платформа и магическая библиотека для читателей и авторов. Пространство, где каждый может создавать, публиковать и читать книги, делиться историями и находить вдохновение.  Платформа включает каталог произведений по жанрам, удобную онлайн-читалку, личные кабинеты авторов и читателей, публикацию книг и глав.
